# Результаты серии на кластере (валидация)

Серия посчитана на кластере (A100) по пяти сидам: 1234, 2345, 3456, 4567, 5678.
Только валидация: ARS 2023 и валидационные годы пяти станций (WNG, CMO, KAK, HUA,
HER). Тестовые годы 2021 и 2024 в этой серии не считались. Подбор параметров шёл
на тех же данных, поэтому оценки не независимы.

| файл | что внутри |
|---|---|
| `validation_results.json` | сводная MAE по 12 длинам для каждой модели, станции, входа и сида (400 прогонов) и среднее ± SD по сидам (104 группы). SD — не доверительный интервал |
| `metrics/experiments/moment-modes-*` | MOMENT: без дообучения, только голова, полное дообучение |
| `metrics/experiments/moment-bf16-*` | контрольный опыт со смешанной точностью BF16 (один сид; F и XYZ) |
| `metrics/seasonal-regimes-*` | сети против сезонного метода по длинам и по возмущённости окон |
| `metrics/event-*` | быстрые пики и события; `analysis.json.gz` — сжатая копия |
| `metrics/mechanism-checks-*`, `alignment-ci-*`, `csdi-padding-*` | диагностика артефактов CSDI на границах пропуска |
| `SHA256.json` | хэши файлов в исходной поставке (файлы `.gz` лежат здесь сжатыми, их хэши — у несжатых оригиналов) |

Скрипты, которыми посчитаны диагностики, — `../../analysis/`: по папке на
каждую папку `metrics/`. Они написаны под раскладку кластера и под валидацию.

Проверка при приёмке: хэши совпали; средние по группам совпадают с
пересчётом по отдельным прогонам; цифры отчёта совпадают с этими файлами;
значения `seadec` на ARS (60, 240, 1440, 4320 мин) воспроизведены независимо
из исходных данных. Веса и дампы предсказаний в поставку не входили.
