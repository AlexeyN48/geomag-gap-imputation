# Восстановление пропусков в минутных записях геомагнитного поля

Минутные записи обсерваторий INTERMAGNET содержат пропуски: отказы питания и
связи, профилактика, замена датчика. Короткие закрывает интерполяция по краям,
но часовые и многосуточные искажают всё, что считается по непрерывному ряду.
Здесь 10 нейросетевых архитектур и классическая интерполяция сравниваются по
единому протоколу — одни окна, одни искусственные пропуски, одна истина — на
6 обсерваториях и 12 длинах пропуска от 5 минут до 3 суток. Выводы проверены
слепым тестом на двух годах по протоколу, записанному до вскрытия тестов
([`PROTOCOL.md`](PROTOCOL.md)).

**Три вопроса.**

1. С какой длины пропуска сеть точнее интерполяции и какая архитектура
   восстанавливает лучше на станции, где обучена.
2. Работает ли модель, обученная на одной обсерватории, на других без
   дообучения, и сколько даёт обучение на самой станции.
3. Что подавать на вход: модуль поля F или три компоненты X, Y, Z, из которых
   модуль собирается.

| CMO | College, Аляска | авроральная зона |
| KAK | Kakioka, Япония | низкие средние широты |
| HUA | Huancayo, Перу | экваториальный электроджет |
| HER | Hermanus, ЮАР | южное полушарие, слабое поле |

| назначение | годы |
|---|---|
| обучение | 2014, 2015, 2016, 2018, 2020, 2022, 2025 |
| валидация — подбор, отбор, остановка | 2023 |
| тест, спокойный | 2021 |
| тест, бурный | 2024 |

Тестовые годы не участвовали ни в обучении, ни в каком-либо выборе. Самый
возмущённый год (2025) отдан в обучение, чтобы сети видели бури до теста.
Обучающий объём у всех станций выровнен по ARS: минуты, где пропуск у ARS,
занулены и у остальных, поэтому сравнение станций не мерит объём данных.

Рецепт сборки данных — `bench_data.py` (INTERMAGNET XML → чистка → докачка
недостающих суток из ГИН → выравнивание); состояние зафиксировано в
`data/DATA_MANIFEST.json` (контрольная сумма, число минут и покрытие каждого
годового файла). Сами годовые файлы в git не хранятся;
`bench_data.py --check` сверяет их с манифестом.

## Постановка и методы

- **Окно** — 6 суток (8640 мин), участки по 5 мин → 1728 токенов. Признаки у
  всех методов одинаковые: значение, маска, sin/cos суток и года. Внешние
  индексы активности (Kp, Dst) не подаются никому.
- **Пропуски** вырезаются искусственно, истина известна. 12 длин в трёх
  режимах: `≤120: {5, 15, 60, 120}` · `120–1000: {240, 480, 720, 1000}` ·
  `>1000: {1440, 2160, 2880, 4320}` мин; 1024 окна на длину. Все методы
  получают побитово одинаковые окна, между станциями окна выровнены по времени.
- **Обучение:** несколько пропусков в окне, лосс — MAE только внутри них,
  12 000 шагов и эффективный батч 16 у всех; чекпойнт — по фиксированному
  валидационному набору.
- **Два входа:** каждая архитектура обучается на модуле F и на компонентах
  X, Y, Z (модуль собирается из предсказанных компонент). Ошибка всегда
  считается по модулю.

| метод | семейство |
|---|---|
| PCHIP, Linear | интерполяция — точка отсчёта |
| seadec, harmreg | сезонные базлайны: суточный профиль + интерполяция; регрессия на гармониках |
| U-Net | свёрточный энкодер-декодер |
| SAITS | самовнимание, спроектированное под импутацию |
| TimesNet | свёртка по двумерной развёртке ряда по периодам |
| ImputeFormer | внимание с проекцией длинной оси |
| TSMixer | MLP-смешивание по времени и признакам |
| N-HiTS | иерархическая интерполяция MLP-блоками |
| N-BEATSx | интерпретируемый базис: тренд + сезонность |
| DLinear | тренд + остаток, линейное отображение |
| SegRNN | сегментная рекуррентная сеть |
| TiDE | плотный энкодер-декодер |
| CSDI | диффузионная модель импутации |
| MOMENT | предобученная фундаментальная модель рядов (AutonLab), дообучение и zero-shot |

**Добавлено по замечаниям к работе.** Сезонные базлайны — сезонная
интерполяция (`seadec`: суточный профиль окна вычитается, ряд
интерполируется, профиль возвращается) и гармоническая регрессия
(`harmreg`: полином + суточные гармоники по наблюдённым точкам окна с
привязкой к краям пропуска); их параметры выбраны на валидации
(`bench_select_baseline.py`). Диффузионная модель CSDI. Фундаментальная
модель MOMENT с предобученными весами AutonLab (дообучение и zero-shot).
Пересчёт всех сетей по 5 фиксированным сидам. Результаты — в разделе «Серия
на кластере», запуск — «Запуск на кластере».

**Подбор гиперпараметров** — одинаковый бюджет на архитектуру: три скорости
обучения при среднем размере, затем три размера при лучшей скорости, 5
обучений × 10 архитектур. Победитель выбирается по 1024 окнам валидации и
допускается, только если ни на одной длине значимо не проигрывает базовой
конфигурации (`models/comp/grid_selection.csv`).

**Метрики и статистика.** Основная — MAE внутри пропуска, рядом RMSE, P95,
NSE. **Score = 1 − MAE / MAE_PCHIP** на тех же окнах: 0 — как интерполяция,
0.5 — ошибка вдвое меньше. Сравнения «A точнее B» — парный блочный бутстрэп
по календарным неделям (2000 повторов); рейтинги — ранги по ячейкам
«неделя × длина», Фридман и Немени. Связи по 5–6 станциям — ранговая
корреляция Спирмена.

## Результаты

**Валидация (ARS, 2023).** Пятёрка финалистов по среднему рангу — U-Net,
SAITS, TimesNet, ImputeFormer, TSMixer; на обоих входах состав одинаков.
Порядок внутри пятёрки зависит от метрики и не утверждается. Интерполяция на
пропусках от 720 мин имеет отрицательный NSE — формы вариации не
воспроизводит; у всех финалистов NSE положителен.

**Слепой тест: 15 утверждений протокола — подтверждено 10, зависит от
обстановки 1, не доказано 3, опровергнуто 1.**

### Метод по длине пропуска

- **До 60 мин** PCHIP значимо точнее каждой сети пятёрки — 15 из 15 сочетаний
  «сеть × длина» в обоих годах; на 5 мин сеть ошибается в 3.3–3.4 раза больше.
- **От 480 мин** каждая сеть значимо точнее PCHIP — 35 из 35 в обоих годах.
  На пропусках от суток Score +0.52 (2021) и +0.48 (2024), то есть ошибка
  примерно вдвое меньше; в возмущённой половине окон исключений 0 из 20.
- **120–240 мин** — переходная зона, граница зависит от архитектуры.
- По RMSE выигрыш меньше (+0.39 и +0.32) и в бурный год падает сильнее:
  сеть промахивается редко, но крупно.

### Шесть обсерваторий

Score на пропусках от суток, медиана по пятёрке:

| станция | обучение на месте, 2021 | 2024 | перенос с ARS, 2021 | 2024 |
|---|---|---|---|---|
| WNG | +0.60 | +0.59 | +0.37 | +0.35 |
| CMO | +0.37 | +0.35 | +0.20 | +0.20 |
| KAK | +0.43 | +0.43 | +0.14 | +0.13 |
| HUA | +0.63 | +0.68 | +0.37 | +0.32 |
| HER | +0.56 | +0.59 | +0.21 | +0.13 |

- При обучении на месте каждая сеть значимо точнее интерполяции на длинных
  пропусках на каждой станции и при обоих входах — исключений 0 из 200.
- **Станции различаются сильнее, чем архитектуры:** медианы по станциям
  расходятся на 0.27–0.33, пять сетей внутри станции — не больше чем на 0.06.
- Качество следует доле регулярного суточного хода на станции (ρ = +0.83 и
  +1.00 для NSE). В бурный год NSE значимо падает только на ARS и WNG; на HUA и
  HER, где регулярного хода больше всего, почти не меняется.
- **Перенос с ARS** без дообучения выигрывает у интерполяции только на
  пропусках от суток; на 240–720 мин — ни у одной модели, в обоих годах.
- Своя модель точнее перенесённой на всех пяти станциях, на 21–56 %. Перенос
  несимметричен; хуже всех переносятся модели с экваториальной HUA.

### Модуль или компоненты

- **Зависит от обстановки.** В спокойном 2021 компоненты значимо точнее
  модуля у U-Net, SAITS, ImputeFormer и TSMixer; в бурном 2024 выигрыш
  сохранился у ImputeFormer и TSMixer, исчез у U-Net и сменился проигрышем у
  SAITS; у TimesNet разницы нет ни в одном году. Величина выигрыша — около 2 %.
- Связи пользы компонент с силой архитектуры и с наклонением поля значимы
  только в одном году из двух — не доказаны.
- Разведочно (после вскрытия, ARS): компонентная модель восстанавливает весь
  вектор, и на пропусках от суток каждая ось точнее интерполяции — Score по X
  +0.35…+0.43, по Y +0.60…+0.64, по Z +0.36…+0.41.

### Выводы

1. Пропуски до часа — интерполяцией, от 8 часов — сетью; на пропусках от
   суток сеть ошибается примерно вдвое меньше, и в спокойные, и в бурные дни.
2. Где заполнять, важнее, чем какую из пяти сетей взять: лучше всего там, где
   силён регулярный суточный ход (экватор), хуже всего в авроральной зоне.
3. Для новой обсерватории лучше обучить модель на её данных; готовая модель с
   другой станции годится только для пропусков от суток.
4. Для точности модуля вход почти не важен; компонентный вход даёт весь вектор
   поля.

**Ограничения.** Подбор гиперпараметров — только на входе-модуле и только на
ARS; у семи архитектур из десяти выбор стоит на краю сетки; у 5 моделей из 20
лучший чекпойнт — на последнем шаге бюджета; один сид на конфигурацию; перенос
проверен с одной станции; связи с геофизикой станций — по 5–6 точкам, поэтому
«не доказано» значит «мало точек», а не «связи нет»; возмущённость окна
определена по самим данным, а не по Kp или Dst.

**Как выглядит восстановление** — `figures/gap_examples/`: типичное
(медианное по ошибке пяти сетей) окно на 60, 720 и 2880 мин; панели X, Y, Z и
модуль из них (`fig_examples_comp_*`), и по сети — модуль на модульном входе
против модуля из компонент (`fig_examples_FvsXYZ_*`).

## Серия на кластере: пять сидов, сезонные базлайны, MOMENT

Считано на кластере (A100) по пяти сидам; **только валидация** — ARS 2023 и
валидационные годы пяти станций. Подбор параметров шёл на тех же данных,
поэтому оценки не независимы. Сводная MAE — геометрическое среднее MAE по 12
длинам, нТл; ± — стандартное отклонение по сидам, а не доверительный интервал.
Тестовые годы в этой серии не считались: гипотезы к ним записаны заранее в
`PROTOCOL.md`, раздел 9. Таблицы — `results/cluster_validation/`.

| метод | вход F | вход XYZ |
|---|---|---|
| MOMENT (полное дообучение) | 2.997 ± 0.020 | 2.942 ± 0.014 |
| U-Net | 2.998 ± 0.027 | 3.063 ± 0.015 |
| SAITS | 3.520 ± 0.079 | 3.451 ± 0.044 |
| TimesNet | 3.627 ± 0.030 | 3.763 ± 0.021 |
| ImputeFormer | 5.178 ± 0.018 | 4.829 ± 0.119 |
| seadec (сезонная интерполяция) | 3.148 | — |
| dayint (суточный шаблон), harmreg | 3.381, 3.486 | — |
| PCHIP, Linear | 3.663, 3.745 | — |

Остальные шесть сетей — 5.1–6.3, CSDI — 6.5–6.7. Пятёрка по среднему рангу на
валидации, усреднённому по сидам: MOMENT, U-Net, SAITS, TimesNet, ImputeFormer
(TSMixer ею не отобран); порядок внутри пятёрки не утверждается.

- **Сезонный метод — сильная точка отсчёта.** По сводной MAE лучше `seadec`
  только MOMENT и U-Net. Но картина зависит от длины: на 60 мин `seadec`
  точнее (1.12 нТл против 1.29 у U-Net и 1.42 у MOMENT), на сутках сети точнее
  на 37 % (5.5 против 8.8 нТл), на трёх сутках — на 31–32 %.
- **Пять станций.** U-Net, обученный на месте, по сводной MAE (вход F) точнее
  `seadec` на College на 11.9 %, на Wingst на 3.5 %, на Hermanus на 3.3 % и
  хуже на Kakioka на 4.7 % и на Huancayo на 4.1 %. Причина — вес коротких
  длин: на пропусках >1000 мин все четыре сети, обученные на месте, точнее
  `seadec` на всех станциях (отношение MAE 0.66–0.86), на ≤120 мин `seadec`
  точнее везде (1.4–5.5 раза).
- **MOMENT.** Без дообучения 9.08 (F) и 9.29 (XYZ), с дообучением только
  головы 8.52 и 8.57, при полном дообучении 2.997 и 2.942: голова не заменяет
  дообучение. Точность близка к U-Net при обучении на одной A100 15.7 ч (F) и
  46.2 ч (XYZ) против примерно 0.12 ч у U-Net. Перенос MOMENT, обученного на
  Арти, на станции хуже U-Net, обученного на месте (на 10–35 %, вход F);
  дообучение MOMENT на станциях ещё не выполнено.
- **Смешанная точность BF16** ускоряет обучение MOMENT в 2.33 раза и меняет
  сводную MAE на −0.43 % — на одном сиде, это контрольный опыт.
- **Быстрые возмущения.** Сети восстанавливают в среднем 2.4–2.7 % амплитуды
  быстрого пика (изменение за 5 мин) на суточных пропусках; упаковка ряда в
  пятиминутные блоки потерь не даёт (ошибка обратного преобразования нулевая).
  Средняя точность не означает восстановления событий.
- **CSDI.** Диффузионная модель чувствительна к положению пропуска внутри
  пятиминутного блока: padding с выравниванием границ пропуска ухудшает MAE у границ на
  53–81 %; универсального исправления не найдено.

Скрипты диагностики — `analysis/`, к ним оговорка: они написаны под раскладку
кластера и валидацию, к тесту не адаптированы.

## Воспроизведение

`IGF_SPLIT` обязателен для каждого скрипта. Из папки `scripts`, PowerShell:

```powershell
$env:IGF_SPLIT = 'comp'
python -u bench_data.py --check
python -u bench_grid.py --stage 1; python -u bench_grid.py --stage 2; python -u bench_grid.py --select
python -u bench_train.py --arch unet --code WNG --cfg ../models/comp/unet_best.json --out ../models/comp/unet_WNG_best.pt
python -u bench_train.py --arch unet --code WNG --cfg ../models/comp/unet_best.json --comp --out ../models/comp/unet_WNG_best_xyz.pt
python -u bench_run.py --method unet_best --code WNG --split test --n 1024
python -u bench_metrics.py --pred dump_unet_best_WNG_comp_test.npz --no-fig
python -u bench_regimes.py --code ARS --split test --tag Fbest --methods unet_best saits_best pchip linear
python -u bench_verdict.py --split test --test-ok
python -u bench_examples_comp.py --code ARS --split test
```

`bench_run.py` по умолчанию берёт 128 окон на длину — для бенчмарка всегда
`--n 1024`. План окон детерминирован зерном, поэтому дампы разных методов
сравнимы побитово.

## Запуск на кластере

**1. Окружение.**

```bash
git clone https://github.com/AlexeyN48/geomag-gap-imputation.git && cd geomag-gap-imputation
python -m venv .venv && source .venv/bin/activate
pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
export IGF_SPLIT=comp
```

**2. Данные и веса.** Передаются файлами: архив данных `geomag_data.zip` и
папка с предобученными весами MOMENT `pretrained/`.

Архив распаковывается в `data/`, и каждый файл сверяется с
`data/DATA_MANIFEST.json` побитово; при расхождении обучение запускать нельзя.

```bash
python -u scripts/data_archive.py fetch --file geomag_data.zip
```

Папку весов положить в `models/` так, чтобы получилось
`models/pretrained/MOMENT-1-{small,base,large}/` — в каждой `config.json` и
`model.safetensors`.

**3. Конвейер.** Этапы идут по порядку: каждый генерирует список заданий
(`scripts/bench_jobs.py` → `cluster/jobs/<этап>.jsonl`), очередь
(`cluster/run_queue.py`) выполняет их по одному на видеокарту. Готовые задания
пропускаются, поэтому прерванный этап продолжается той же командой.

```bash
bash cluster/run_all.sh                    # все этапы подряд
bash cluster/run_all.sh seeds seedval      # только перечисленные
sbatch cluster/slurm_stage.sh seeds        # один этап под SLURM
```

Порядок этапов повторяет логику работы: всё, что выбирается, выбирается на
валидации; тестовые годы считаются последним этапом.

| этап | ресурс | что делает | заданий |
|---|---|---|---|
| `baselines` | CPU | PCHIP, Linear, суточный шаблон, сезонная интерполяция, гармоническая регрессия на валидации всех станций | 30 |
| `grid1`, `grid2` | GPU | подбор CSDI и MOMENT (5 обучений на архитектуру, как у остальных) | 6 + 4 |
| `griddumps`, `select` | GPU, CPU | ячейки на валидации, выбор победителя → `models/comp/<арх>_best.json` | 10 + 1 |
| `seeds` | GPU | все 12 сетей на ARS, оба входа, сиды 1234, 2345, 3456, 4567, 5678 | 120 |
| `seedval` | GPU | их прогоны на валидации ARS | 120 |
| `finalists` | CPU | пятёрка по среднему рангу на валидации, усреднённому по сидам → `data/comp/seeds/finalists.json` | 1 |
| `stations` | GPU | финалисты, обученные на каждой из 5 станций, оба входа, 5 сидов | 250 |
| `stationval` | GPU | их прогоны на валидации своей станции | 250 |
| `test` | GPU, CPU | тестовые годы: базлайны и все сети на ARS, перенос финалистов ARS на станции, модели станций на всех 6 станциях | ~3800 |
| `summary` | CPU | среднее и разброс по сидам → `data/comp/seeds_summary.csv` | 1 |

Дообучение MOMENT на станциях входит в этап `stations`: пятёрка финалистов
включает MOMENT, а готовые задания пропускаются. Для многочасовых запусков
можно включить возобновление с контрольной точки: `export IGF_AUTO_RESUME=1`.

**4. Интервалы и вердикты** (после `stationval`; нужны дампы `baselines`):

```bash
python -u scripts/bench_station_ci.py --split val
python -u scripts/bench_station_ci.py --split val --stations ARS --per-length
python -u scripts/bench_station_ci.py --split val --stations ARS --per-length --subset act
python -u scripts/bench_verdict_cluster.py --splits val
```

Сид меняет только начальные веса и порядок обучающих окон: окна валидации и
тестов у всех сидов одни и те же, поэтому разброс относится к обучению.
Вывод CSDI дорогой (50 шагов диффузии на окно) — его прогоны самые долгие.
