# Диагностики серии на кластере

Скрипты, по которым посчитаны таблицы в `results/cluster_validation/metrics/`
(одноимённые папки). Это не часть конвейера `bench_jobs.py`: они читают готовые
дампы предсказаний (`data/comp/...`) и веса и пишут только в свои папки.

Оговорки:
- написаны под раскладку кластера (`--root` — корень проекта с дампами и
  весами); часть скриптов проверяет наличие метки `cluster/control/hold_station_training.json`
  и без неё остановится;
- привязаны к валидации ARS 2023; для теста их нужно адаптировать;
- в репозитории не запускались; воспроизводимость числа проверялась только
  по готовым JSON.
